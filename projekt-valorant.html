Lernperiode 7

Valorant-API Frontend

Eine Website, die Daten aus einer öffentlichen, inoffiziellen API abruft und in einer eigenen Oberfläche darstellt. Dazu gehören Suche, Vergleich, Quiz und ein Hell-/Dunkelmodus.

Ziel

JavaScript praktisch anwenden statt nur Übungsaufgaben lösen. Eine offene API war dafür ideal: Die Daten waren vorhanden, die Arbeit lag darin, sie abzurufen und so darzustellen, dass jemand etwas damit anfangen kann.

Als Thema habe ich Valorant gewählt, weil ich das Spiel kenne. Bei einem Datensatz, dessen Inhalt man versteht, fällt sofort auf, wenn etwas falsch angezeigt wird.

Technologien

JavaScript · HTML · CSS · REST-API

Funktionen

  • Übersichten zu Agents, Waffen, Maps, Skins und Gamemodes
  • Such- und Filterfunktion, zum Beispiel nach Rolle oder Preis
  • Detailansicht pro Element mit zusätzlichen Infos und Bildern
  • Vergleichsmodus für Waffen und Agents
  • Mini-Quiz: Fähigkeit dem passenden Agent zuordnen
  • Random-Generator für Agent, Waffe oder Map
  • Hell-/Dunkelmodus-Umschalter

Vorgehen

Zuerst habe ich die API-Antworten angeschaut, bevor ich eine Zeile Oberfläche gebaut habe: Welche Felder gibt es, wie sind sie verschachtelt, was fehlt bei einzelnen Einträgen? Danach kam die einfachste Version, eine Liste aller Agents, und erst als die stand, die Detailansicht.

Jede weitere Funktion war ein eigener Schritt: erst Suche, dann Filter, dann Vergleich. Beim Quiz und beim Random-Generator konnte ich Code wiederverwenden, den ich vorher fürs Filtern geschrieben hatte. Das hat mir gezeigt, dass sich die Aufteilung in kleine Funktionen auszahlt.

Stolpersteine

  • Verschachtelte Daten: Fähigkeiten stecken innerhalb eines Agents nochmals in einer eigenen Liste. Bis ich sauber durch beide Ebenen kam, hat es gedauert.
  • Nicht jeder Eintrag ist vollständig. Fehlende Bilder oder Beschreibungen haben die Anzeige zerschossen, bis ich diese Fälle abgefangen habe.
  • Für jeden neuen Endpunkt brauchte ich JavaScript-Methoden, die ich vorher nicht kannte. Anspruchsvoll, aber genau deshalb lehrreich.

Was ich gelernt habe

  • fetch liefert ein Promise. Ohne await arbeitet der Code mit noch leeren Daten weiter.
  • Verschachtelte JSON-Strukturen: Die Fähigkeiten liegen als eigenes Array innerhalb eines Agents, also zwei Ebenen tief.
  • Fehlende Felder abfangen, bevor sie ins HTML geschrieben werden. Sonst steht undefined in der Anzeige.
  • Array-Methoden wie filter und map für Suche und Filter statt eigener Schleifen.
  • Farben über CSS-Variablen steuern. Der Hell-/Dunkelmodus tauscht nur die Werte, nicht die Regeln.
